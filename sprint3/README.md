# Kampüs Etkinlik Portalı - Sprint 1

Bu proje, kampüsteki etkinliklerin listelendiği, detaylarının görüntülendiği ve yeni etkinlik ekleme/güncelleme formlarının yer aldığı saf HTML tabanlı bir web uygulamasıdır.

## Proje Yapısı

`sprint1/` klasörü içerisinde aşağıdaki 7 dosya yer almaktadır:
- `index.html`: Ana sayfa, öne çıkan etkinlikler ve duyurular.
- `etkinlikler.html`: Tüm etkinliklerin listesi ve ayın programı özeti.
- `etkinlik-detay.html`: Etkinlik detay ve künye bilgileri.
- `etkinlik-ekle.html`: Yeni etkinlik ekleme formu.
- `etkinlik-guncelle.html`: Var olan etkinliği güncelleme formu.
- `.gitignore`: Git tarafından izlenmeyecek dosyalar listesi.
- `README.md`: Proje açıklama belgesi.

## Kullanılan Teknolojiler
- HTML5 (Semantic HTML etiketleri kullanılmıştır)
